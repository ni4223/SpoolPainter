# SpoolPainter — Project Structure

## Top-level
```
SpoolPainter/
├── .kiro/
│   ├── steering/
│   │   ├── aws-aidlc-rules/   # AIDLC core workflow (do not edit)
│   │   ├── product.md         # this project's product context
│   │   ├── structure.md       # this file
│   │   └── tech.md            # tech stack
│   ├── aws-aidlc-rule-details/  # AIDLC stage details (do not edit)
│   └── AIDLC_VERSION
├── aidlc-docs/                # generated by AIDLC sessions (state, audit, artifacts)
├── app/                       # Android app module
├── gradle/
├── build.gradle.kts
├── settings.gradle.kts
├── CLAUDE.md                  # entry point for Claude Code
└── README.md
```

## App module
```
app/src/main/
├── AndroidManifest.xml
├── java/com/spoolpainter/app/
│   ├── ui/
│   │   ├── activity/MainActivity.kt
│   │   ├── MainViewModel.kt
│   │   ├── screens/           # SpoolPainterScreen, MainScreenContent, SettingsScreen
│   │   ├── components/        # FilamentForm, MaterialSelector, ColorSelector, etc.
│   │   └── theme/Theme.kt
│   ├── hardware/nfc/          # NfcManager, NfcController, NfcHandler
│   ├── domain/models/         # OpenSpoolData, FilamentSpool, SpoolmanModels, etc.
│   ├── data/
│   │   ├── local/             # MaterialDatabase, BrandDatabase
│   │   └── remote/spoolman/   # SpoolmanService (Retrofit)
│   └── ...
└── res/                       # layouts (minimal), drawable, values, mipmap
```

## Where things go
- **New Compose screen** → `ui/screens/`
- **Reusable Compose component** → `ui/components/`
- **Domain model / data class** → `domain/models/`
- **NFC logic** → `hardware/nfc/` (keep Android NFC API isolated here)
- **Spoolman API** → `data/remote/spoolman/`
- **Local presets / static data** → `data/local/`
- **ViewModel state** → extend `MainViewModel` or split per-screen as v2 grows

## AIDLC artifacts
All AIDLC-generated artifacts (requirements, designs, plans, audit) go under
`aidlc-docs/`. Never put application code there. Never put AIDLC docs in `app/`.
