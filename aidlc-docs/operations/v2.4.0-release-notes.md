## Play Console release notes (paste as-is, no Markdown, `•` bullets)

```
Reuse a filament as a template
• Clearing the Filament picker with the X now only unlinks it. Every value stays, so you can pick a similar filament, change the colour, and save it as a new one.
• New Clear all in the top-right menu resets the whole form in one tap.

Smarter picker
• Once you pick a brand, matching filaments float to the top of the Filament picker, best match first. Before, this only happened after reading a tag.
• Search now matches brand and material together, so "3dhojor petg" finds it.

Fixes
• A selected spool now refreshes from Spoolman when you pull to refresh or return to the app, so remaining weight stays current. Your unsaved edits are never overwritten.
• Brands that differed only by stray whitespace no longer appear twice in the Brand list.
• The Variant field now accepts dots, so labels like "PLA 2.0" are kept.
```

## What is in it

### U22 — selected-spool refresh + variant dot
- A selected spool re-derives from Spoolman on pull-to-refresh **and** on app
  resume, with a clobber guard so an edited form is left alone. Verified on device
  against a spool the printer was actively consuming (remaining weight tracked
  556.4 → 554.6 across refreshes).
- `.` added to the Variant allowlist.
- Multi-colour hex (UI-50) was pulled from scope mid-unit and is still on hold.

### U23 — search + sister filament + brand dedupe
- Picker search tokenises the query and requires every token, so brand + material
  queries work across fields.
- The Filament X unlinks instead of resetting, which is what makes a sister
  filament usable as a template; `Clear all` in the `⋮` menu carries the reset.
- Brand rows differing only by whitespace now dedupe.
- Brand casing was investigated and deliberately **not** changed.

### U24 — form-driven float
- The Filament picker floats scorer-ranked matches built from the form's own
  fields, gated on a brand being set so an untouched form never floats anything.
- A tag read still takes precedence, and nothing floats while something is
  selected.

- **Multi-colour hex (UI-50 Ask 1)** on hold pending the U1-support question.
- **UI-53** (NFC dispatch going deaf after a few reads) fully root-caused but
  parked; it is the strongest candidate for the next unit and is the
  highest-severity open tester report.
- **UI-58** (edits to a prefilled filament dropped on Create spool) traced but
  unconfirmed; U23's design routes around it.
- **UI-59 reading (b)** (read-derived float in the Material / Brand / Colour
  pickers) still open.
- The "What's new" sheet still shows the evergreen v2 showcase copy, so updaters
  will see it once after this update. Unchanged behaviour since 2.1.x.
