### Play review block on 117, fixed in 118

Play refused to send 117 for review: "Required hardware feature declarations are
restricting your app's availability": `android.hardware.nfc` and
`android.hardware.screen.portrait` ("affects Phone, Tablet, Desktop and Android XR
users"). The manifest was byte-identical to 2.4.1, so this is a new Play check.
Decided (maintainer): both marked `required="false"`. On a device with no NFC,
Read and Write say "This device has no NFC. You can still edit spools in
Spoolman." Write says it before any Spoolman write. NFC turned off keeps
"NFC not available". Verified in the built APK (`aapt2 dump badging`): nfc,
screen.portrait and camera.any are `uses-feature-not-required`.

**Not changed:** `android.hardware.camera` is still implied-required by the CAMERA
permission (as in 2.4.1; Play did not flag it). Making it optional would need the
colour sampler to handle a missing back camera: `bindToLifecycle(DEFAULT_BACK_CAMERA)`
in `CameraColorSampler.kt` would throw.

## Play Console release notes — Open testing (paste as-is). 455 characters.

Testers are on **2.4.1 (116)**, so this covers 2.4.2 only.

```
Fixes
• Saving weight to Spoolman now works for filaments with no temperature or colour set. If Save is greyed out, the app tells you why.
• Measured weight uses the brand's empty-spool weight when the spool has none.
• Overfilled spools save their exact weight.
• Save no longer overwrites a filament's own temperatures.
• Transparent colours from Spoolman show correctly and are kept when you save.
• New Snapmaker tags read, including PETG Translucent.
```

Left out (no room or not worth it): spools with no starting weight in Spoolman
now take weight edits; "No changes" instead of "Updated"; unknown Snapmaker codes
still read; the coupon code removed from Settings.

**Not verified on a real PETG Translucent tag** (the maintainer has none). It is
covered by unit tests on a real Snapmaker dump with the type bytes rewritten, and
by studiofuga's report on PR #13.
