# SpoolPainter v2.0 — Tester Release Notes

Thanks for testing SpoolPainter v2.0! This is the first release of the v2 rewrite, shipped to the Play Store testing track. Same package id as v1 (`com.spoolpainter.app`), so the upgrade installs in place — no migration needed (your data lives on tags + Spoolman, not in the app).

## What's new

- **Cleaner architecture** — Hilt DI, MVVM, repository layer, single Activity with Compose-only screens.
- **Read-and-pair flow** with vendor tag classification (Bambu / Creality / Anycubic / Snapmaker / TigerTag tags are detected and surfaced rather than silently failing).
- **Create-and-pair flow** with `extra.variant` + `extra.card_uids` round-trip to Spoolman.
- **Pair another tag** — second-tag pairing prompted via a bottom sheet; both UIDs land on the same Spoolman spool.
- **Move-on-bind** — taking a tag from spool A → spool B sweeps source spools instead of leaving partial state.
- **Side modes** — Raw write (no Spoolman binding) and Vendor UID-only pair (bind a vendor tag's UID without writing payload).
- **Pickers + filament metadata** — Material / Variant / Color / Brand pickers with custom-entry support; filament metadata expander supports PATCH-on-edit.
- **Settings**
  - Independent sort orders for spool dropdown (Material / Brand / ID / Last Used) and filament picker (Material / Brand / ID)
  - Theme switch (Light / Dark / System dynamic colour on Android 12+)
  - Currency selector ($ / € / ¤)
  - Spoolman URL config — Save runs the connectivity probe
- **Spoolman gating** — Spoolman-only form sections hide when no URL is configured and disable (visible) when configured but unreachable.
- **IME-aware snackbars** — feedback stays visible with the keyboard up.

## Known issues / parked

The following are known and explicitly **out of scope** for v2.0; tracked for a later release:

- **Edit a paired spool** — change material / brand / colour / temps after pairing. Coming post-v2.0.
- **Archive a spool from the app** — coming post-v2.0.
- **Filament-metadata edit-on-existing-spool** — diff-and-PATCH flow with confirmation. Coming post-v2.0.
- **Vendor tag content decoding** — Bambu / Creality / Anycubic / Snapmaker / TigerTag tags are *classified* in v2.0 but their content isn't decoded. v2.1 (U11) ports the OpenRFID parsers to Kotlin so vendor tags can be read directly without re-pairing.
- **Vendor key management** — per-vendor key list with keystore-backed encrypted storage. v2.1 (U12).
- **GPL-3.0 license transition** — the project carries no LICENSE today (effectively "All rights reserved"). v2.1 transitions atomically to GPL-3.0.

## Build prerequisites

If you're building from source rather than installing the testing-track APK:

- JDK 17 — `JAVA_HOME` must point to a JDK 17 install
- Android Studio Iguana or newer
- Gradle wrapper handles the rest (Gradle, Kotlin, plugins)

For release builds (signed APK / AAB):
- Local keystore at `~/spoolpainter-release-key.jks`
- One of: `KEYSTORE_PASSWORD` env var, or `~/spoolpainter-keystore.pwd` text file containing the password

## How to provide feedback

- File issues on the GitHub repo
- Use the testing-track feedback form (link distributed with the testing-track invite)

When reporting a bug:
- Describe what you expected and what happened
- Include the device model and Android version
- If it's NFC-related, mention the tag type (NTAG213/215/216 or vendor) and the Spoolman version you're running
- For Spoolman-related bugs, attach the URL pattern (sanitise the IP) and any visible error message

## Testing focus areas

If you have time, these are the areas where extra eyes help most:

1. **Vendor tag classification** — try Bambu / Creality / Anycubic / Snapmaker tags from real spools; confirm they surface as vendor tags rather than crashing.
2. **Snapmaker U1 round-trip** — write a tag, read it on a Snapmaker U1, confirm `lot_nr` lookup works.
3. **Spoolman gating** — toggle your Spoolman URL between configured/blank and reachable/down; confirm the form sections show/hide/disable correctly.
4. **Sort + currency persistence** — change the spool sort, the filament sort, and the currency; cold-start the app; confirm everything sticks.
5. **R8 release build** — if you sideload the signed APK rather than the debug build, confirm nothing unexpected breaks (UI, navigation, sheet flows). Release runs through R8 minify; debug doesn't.

Thanks again — your feedback shapes v2.1.
